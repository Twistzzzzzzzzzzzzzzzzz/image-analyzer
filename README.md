# Image Analyzer

Claude Code Skill —— 让 Claude 结构化分析图片内容，五大场景一键输出。

A Claude Code Skill that gives Claude structured image analysis capabilities across five scenarios with professional output templates.

[![Platform: Claude Code](https://img.shields.io/badge/Platform-Claude%20Code-blue.svg)](https://claude.ai/code)

## 安装 / Installation

```bash
npx skills add https://github.com/Twistzzzzzzzzzzzzzzzzz/image-analyzer.git
```

或手动克隆 / Or manually:

```bash
git clone https://github.com/Twistzzzzzzzzzzzzzzzzz/image-analyzer.git ~/.claude/skills/image-analyzer
```

## 五大场景 / Five Scenarios

| # | 场景 Scenario | 说明 Description | 触发示例 Example |
|---|-------------|-----------------|-----------------|
| 1 | **截图分析** Screenshot | 识别软件界面、网页、App 的布局、元素和交互状态 | `"看看这个报错截图"` `"这个页面哪里有问题"` |
| 2 | **UI 审查** UI Review | 设计稿可用性评估、排版分析、改进建议 | `"review 这个登录页设计"` `"这个 UI 有什么问题"` |
| 3 | **图表解读** Chart & Diagram | 数据图表、流程图、架构图的结构化解读 | `"这个架构图什么意思"` `"分析这个折线图的趋势"` |
| 4 | **OCR 提取** OCR | 从图片中提取文字，保留原文格式 | `"提取这张菜单里的文字"` `"图片上写了什么"` |
| 5 | **照片描述** Photo | 场景、主体、环境、氛围的全面描述 | `"这张照片里有什么"` `"描述一下这张图"` |

### 关键元素

|----------|-------------------|--------|

### 场景 5：照片描述

> 用户：`看看这张照片里有什么`

```markdown
## 照片描述

### 场景概述
黄昏时分的海边码头，木质栈道延伸至海面，远处天空呈现橙粉渐变色。

### 主体识别
- 主要物体：木质栈道、远处灯塔、停泊的小船
- 人物：无
- 动物/植物：栈道旁有少量海草

### 环境与背景
- 地点类型：室外 / 海边
- 光线条件：自然光 / 黄金时刻（日落前）
- 背景细节：天空云层呈放射状，海面微波

### 细节观察
- 色彩：暖色调为主（橙、粉、金），水面反射天空颜色
- 构图：栈道引导线从右下延伸至左侧海面，形成纵深
- 值得注意的细节：栈道木板有轻微风化和水渍痕迹

### 情绪与氛围
宁静而温暖的黄昏氛围，画面传达出放松和孤独感。
```

## 特性 / Features

- **5 种结构化模板** —— 输出专业一致，告别随意描述
- **批量处理** —— 一次分析多张图片，自动对比总结
- **3 种输出模式** —— 详细报告 / 简短描述 / 纯文字提取，按需选择
- **中文输出** —— 分析用中文，原文文字保留原语言
- **隐私提醒** —— 涉及人脸、证件号时自动提示保护
- **置信度标注** —— 不确定的内容用 `[不确定]` 标记，不胡乱猜测

## 输出模式 / Output Modes

| 模式 | 触发词 | 说明 |
|------|--------|------|
| **详细报告**（默认） | "分析" "审查" "详细" "review" | 使用完整模板输出 |
| **简短描述** | "大概看看" "简述" "快速看下" "quick" | 场景概述 + 核心要点 |
| **纯文字提取** | "提取文字" "只要文字" "OCR" | 只输出提取的文本，OCR 场景可用 |

## 使用 / Usage

在 Claude Code 中直接对话即可，无需特殊命令：

```
分析这张截图：/path/to/screenshot.png
帮我看看这张照片里有什么
review 这个 UI 设计稿
提取这三张图片里的文字
这个架构图说明了什么
```

也可以处理 URL 图片（skill 会自动下载后分析）。
